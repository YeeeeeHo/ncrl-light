## 2. 계산은 어디에 쓰이나 (측정, RTX 4070)
- 학습 wall-clock의 99%가 업데이트다(epoch당 업데이트 362초, 수집 4초)
- 업데이트 1회 2.92초 = WM 1.21초(41%) + 상상·actor-critic 1.71초(59%)
- WM은 64-step 순차 scan이라 대역폭에 묶이고, 상상은 연산에 묶인다. 그래서 FLOPs 비중과 시간 비중이 다르다
- WM 업데이트를 완전히 빼도 −32%가 상한이다(상상 시작점용 forward 274 ms가 남음)
- encoder·decoder freeze는 −4~9%. GRU freeze는 −34%(WM 업데이트 시간 기준)

## 3. WM 업데이트는 무엇을 배우나 (측정, 40k 스냅샷)
- 이미 학습한 에피소드의 오차 10.8 vs 다음 에피소드 73.0 (사전학습 모델 90.3). 업데이트 대부분이 리플레이 버퍼를 맞추는 데 쓰인다
- rehearsal 데이터 오차는 유지(65 → 66). 다른 embodiment는 망각(cartpole 0.66 → 31.6)
- encoder + decoder를 사전학습 값으로 되돌려도 새 데이터 동역학 오차는 +3%. 일반화 이득은 주로 RSSM에서 온다

## 4. 분기 파일럿 결과 (Quadruped Walk, base run seed 1, 분기 seed 7, 팔당 +20k frame)

**시점별 WM OFF 손실 (원본 대비)**

| 분기 시점 | 최종 eval 차이 | AUC 차이 | 원본이 20k 동안 올린 점수 중 OFF가 얻은 비율 |
|---|---:|---:|---:|
| 20k | −156 | −61 | 28% (62/218) |
| 40k | −171 (원본 3회 평균 882 대비) | −67 | 43% (131/302) |
| 60k | −73 | −15 | — (원본이 이미 정체: +18, OFF는 −55) |

**읽는 법**
- **WM 1/4는 원본과 구분되지 않는다**(40k 분기: 895 vs 846–914). 시간은 −24%다
- **WM OFF는 20k·40k에서 약 150–170점 낮다.** 이는 40k 원본 3회의 흔들림(최종 eval 846–914, 폭 68)보다 크다
- **60k에서 손실이 작아졌다**(−73, AUC −15). 하지만 이 시점의 원본은 이미 정체 상태(897 → 915)다. OFF는 첫 10k 동안 원본과 같다가(917) 이후 842로 내려갔다. 즉 학습이 아니라 **유지**에 WM 업데이트가 필요했을 수 있다. 천장 효과 때문에 "후반엔 덜 필요하다"고 단정할 수 없다
- 학습 중 return(짝 차이 −12 ~ +68)은 OFF와 원본의 차이를 거의 보여 주지 못한다. guidance 구간(확률 20k 0.8, 40k 0.6, 60k 0.4)에는 BC 정책이 행동하므로 에이전트 실력 차이가 가려지는 것으로 추정한다. 판단 지표는 eval로 둔다

## 5. 가설 상태
| 가설 | 상태 |
|---|---|
| 모든 **모듈**을 매번 업데이트할 필요는 없다 | 약함. 처음부터 freeze하면 해롭고(논문 Fig. 8), encoder·decoder freeze는 절감 4–9%뿐. GRU freeze는 대기 중 |
| **매번** 업데이트할 필요는 없다 | 지지 신호 (1/4: 손실 미검출, −24%) |
| WM 업데이트가 **아예** 필요 없다 | 반대 신호 (20k·40k에서 −150점 이상) |
| 손실이 **학습 시점**에 따라 줄어든다 | 60k에서 줄었으나 천장 효과와 구분 불가 |
| **예측 오차로** 필요성을 판단 | 미검증 |

**연구 방향에 대한 함의**: WM 쪽 절감 상한은 32%인데 고정 1/4로 이미 24%를 얻는다. 적응형 판단 방법의 추가 여지는 작다. 따라서 (a) 고정 빈도가 깨지는 경우(Meta-World, 초반)를 찾거나, (b) 상상 시작점 축(업데이트 시간의 59%)과 결합해야 논문 기여가 된다.
